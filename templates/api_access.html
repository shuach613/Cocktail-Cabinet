HOW TO CONNECT

Use your API

Send your token in an Authorization: Bearer header over HTTPS. Browser sign-in cookies do not authenticate API requests. API photos are private and use the same header.

GET /api/v1/recipes
Authorization: Bearer YOUR_PERSONAL_TOKEN

The versioned API supports listing, creating, editing and removing recipes, managing ingredient categories, and downloading or uploading recipe photos. Machine-readable documentation: GET /api/v1/openapi.json (requires a token). Updates appear in the app automatically when a collection page is open.
